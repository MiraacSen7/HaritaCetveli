# Harita Cetveli

Harita bilgisi hesaplarını (ölçek, rakım, coğrafi ve grid koordinat, MGRS, milyem/derece, İSA, P noktası, GİA–MİA, pafta) bilinen sayıları yazarak çözüm adımlarıyla hesaplayan, internetsiz çalışan web uygulaması.

## iPhone'a kurma
1. Yayın adresini iPhone'da **Safari** ile aç.
2. Paylaş düğmesi → **Ana Ekrana Ekle** → Ekle.
3. Ana ekrandaki **Harita Cetveli** simgesine dokun. Bir kez açıldıktan sonra internet olmadan da çalışır.

Android'de aynı adres Chrome ile açılıp **Ana ekrana ekle / Uygulamayı yükle** ile de kurulabilir.

## Dosyalar
- `index.html` — uygulamanın tamamı (HTML, CSS, JavaScript tek dosyada)
- `sw.js` — çevrimdışı çalışma için service worker
- `manifest.webmanifest` — ana ekran simgesi ve uygulama adı
- `icons/`, `fonts/` — simgeler ve gömülü Barlow yazı tipleri (SIL Open Font License)
